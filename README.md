# Assignment 3 — NLP

Основной файл: [Assignment_3_NLP.ipynb](Assignment_3_NLP.ipynb)

Откройте его в Google Colab или Jupyter и выберите «Выполнить всё».
Рекомендуется Python 3.10–3.12 и чистое ядро. GPU и API-ключи не нужны.
При первом запуске требуется интернет для библиотек, открытых корпусов и моделей.
Пять исходных статей встроены в ноутбук.

Ноутбук содержит:
1. VADER и Logistic Regression для трёх классов тональности.
2. Экстрактивную и абстрактивную суммаризацию, оценку и авторскую редактуру сводки.
3. Анализ 40 уникальных песен четырёх жанров.
4. Восемь классификаторов языка и предобученный fastText на WiLI-2018.
5. Ответы на 15 контрольных вопросов.

Промежуточные загрузки: nlp_assignment_data/
Результаты запуска: nlp_assignment_results/
Источники, версии и контрольные суммы: nlp_assignment_results/run_manifest.json

Ограничение: базовая T5-small теряет важные темы при сильном сжатии.
В ноутбуке показаны её настоящий результат, анализ пропусков и отдельная вычитанная
аннотация. Авторская редактура не выдаётся за машинный вывод.

Скачанные модели, исходные корпуса и отдельные файлы результатов не включены в репозиторий.
Ноутбук загружает данные автоматически и сохраняет результаты при запуске.
Таблицы и графики проверенного запуска уже сохранены в выводах ячеек ноутбука.
